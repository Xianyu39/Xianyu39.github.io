# 引子
大语言模型，简称为大模型或LLM，给自然语言处理领域带来了革命性的突破，是当前最炙手可热的研究领域之一。但是在此之前，我却总是当它是一个常识，从未给其写过一个系统性的介绍。这次借着写相关公众号文章的机会来补全这个空白。
# 原理
大模型原理的研究有很多，但是就像许多神经网络一样，关于其内部的原理，以及为什么大模型可以表现得这么好仍然是未知的，有待进一步研究。本文主要介绍一下关于大模型结构以及我们如何训练得到大模型。
## 自回归
当前的大模型其实都是**自回归**序列生成模型，即模型一个一个元素地生成整个序列，且每个元素都是模型利用输入以及之前的输出生成的。设模型为$f$，输入序列为$X=x_{1},x_{2},\dots,x_{k}$，输出序列$y_{1},y_{2},\dots,y_{l}$的方式为：
$$
\begin{cases}
y_{1}=f(X) \\
y_{2}=f(X;y_{1}) \\
 \dots\\
y_{i}=f(X;y_{1},y_{2},\dots,y_{i-1}) 
\end{cases}
$$
这种生成方式可以生成任意长度的输出序列。一般来说，我们会设定一个特殊符号`[END]`，当模型某一轮输出了这个符号或达到了设定的最大生成长度就停止生成。如果把上面说的符号换成自然语言token，于是我们就得到了现在最常见的大语言模型，如下图。
> [!NOTE] Token
> 在自然语言处理中，一段文字往往被看作由一组token组成。Token是大多数自然语言处理研究中自然语言序列的基本元素，当前没有合乎其含义的中文翻译。大多数情况下，一个token看起来就像一个词；但是像是"relationship"这样的词也往往会被拆成"relation"和"#ship"两个token。总的来说，token是介于字和词之间的一个概念（在英语中就是介于字母和单词之间）。

由于这种自回归架构，大模型实质上完成的任务是「根据已有的一段话预测出下一个token」。由于之前的输出也会输入进去参与后面所有token的预测，影响之后的每一次输出，因此自回归模型对输入和自己的输出是极度敏感的。你就算只修改了输入中一个看似无关紧要的字，也可能导致模型输出的内容大相径庭。

那么什么样的模型可以胜任「预测下一个token」的任务呢？目前来说通用的解决方案都是 Decoder-Only Transformer。虽然传统 Transformer、Mamba 等模型理论上效果也很好，但是实践上综合了成本、可拓展性等多个方面之后的相对优解就是 Decoder-Only Transformer。后面的各种新兴架构，包括MoE 等，都是在这个基础上做了微创手术一样的修改。
## 训练
大语言模型并没有在模型结构上有太多创新，其表现出来的能力主要来自于其巨大的规模和海量训练。大模型的训练主要包含：
1. **预训练（pretrain）**：用大量的文本训练，模型可以获得基础的自然语言能力，但是其并不会服从指令；
2. **监督微调（supervised fine-tune）**：用一些问答对数据集来微调预训练后的 LLM，经过 SFT 之后它就学会了服从用户的指令办事，回应用户的请求；不过此时它生成的内容往往不可靠，或者存在安全性问题。这在 `gpt3.5` 时期非常明显；
3. **对齐（alignment）**：训练模型使其学会按照人类的喜好为人们解决问题。通常使用 RL 来完成。这个步骤可以有效提升 LLM 解决问题的能力，是目前各家 LLM 公司竞争的焦点。DeepSeek 便是提出了一种强化学习方法从而名声大噪。
### 预训练
大模型的预训练和BERT颇为相似，为了绕过人工打标签的高额成本，大模型和BERT都采取了自监督方法。即将互联网上的自然语言文本进行挖空、去掉后半句等操作，再要求模型预测出被挖去的部分。靠这种方法，数据集规模只取决于能获得多少自然语言文本，因此才有了足够的数据去训练规模如此之大的模型。
为了训练第一代大模型（GPT3.5），OpenAI几乎下载了互联网上存在的所有网页来作为训练材料，并且在巨大规模的算力之下进行长时间训练，才获得了第一个能够说人话的模型。从这个角度来看，大模型的成功在原理上的创新其实有限，更多是一种大力出奇迹的感觉。
### 微调
预训练可以让大模型掌握语法以及数据集中包含的知识，但是并不能让大模型能够说人话。只经过预训练的大模型不知道人如何对话，它只会根据直觉在输入后面进行补写。要让它能够正常对话，还需要进行微调。Hugging Face上标注instruct的大模型就是未经微调的模型。

微调需要的数据并不多，只需要一组对话示例（数千条）即可。当前而言，微调已经成为了我们改造大模型的主要手段之一。我们只要通过特定的数据，就可以通过微调得到各种性格各异、掌握不同领域知识的大模型。各家公司推出的面向不同场景的大模型，比如专门面向数学问题的 math 模型、擅长编写代码的 code 模型，基本上就是微调的结果。下图是阿里团队推出的面向不同领域的微调大模型：
由于大模型的参数过多，即使只是使用少量数据进行微调也要求比较昂贵的设备并且需要消耗大量算力。在这样的背景下，参数高效微调（PEFT）应运而生。参数高效微调指的是一类可以有效减少微调大模型所需的计算量的手段。常见的参数高效微调手段包括适配器（加入一个新的可训练模块，然后只对这个模块进行训练）、选择大模型中一部分参数进行微调、重参数化等（如下图）。在大模型吸引全世界注意力的当前，PEFT 仍然是一个热度很高的研究领域。关于这部分内容，后续会写文章详细介绍。

## 改良
原生大模型在展现出人一样的智慧的同时也具有某些和人很相似的缺点。用过 OpenAI 早期推出的 GPT 3.5 的用户应该知道，GPT 3.5 常常会信誓旦旦地给出一些虚假、错误信息，比如推荐完全不存在的书籍、捏造完全不存在的历史人物等等。大模型经常会像一个不靠谱的人一样，给出一些像梦一样不靠谱的内容。这种现象有个很形象的名字：机器幻觉（Hallucination）。机器幻觉的存在打破了科幻小说中人工智能绝对冷静、绝对可靠的形象，也给众多学者提供了新的研究课题。

目前而言，并没有能够完全解决机器幻觉问题的方法，但是有许多思路都可以改善大模型的表现，让大模型提供的内容更加靠谱。比如外接搜索引擎的大模型（RAG）、改造了思考方式的大模型（比如CoT）、以及会互相讨论并且自我反思的大模型等。
# 应用
## 文本处理
因为大语言模型具有强悍的自然语言理解能力，所以我们经常用大语言模型处理文本。
1. 生成知识图谱：从一段文本中抽取三元组；
2. 生成数据：根据一些材料（文本或者是结构化数据），生成问答数据、事实验证数据等。
3. ……

> [!note] Instruct 模型的优势
> instruct 模型除了可以用来各种微调，还可以用来生成数据。instruct 模型很擅长**补写**任务，在给出提示词的情况下，instruct 模型可以生成很好的格式化数据，而且保证没有废话。
